## 4. Integration with vacancy sources

Vacancy data is pulled from the page of a **source** — hh.ru, getmatch.ru, it-vacancies.ru or
geekjob.ru. §4.8 defines the source concept, the provider registry and dispatch by `vacancy_source`
(it-vacancies.ru's specifics are in §4.8 itself); §4.9 covers getmatch.ru; §4.13 covers geekjob.ru;
§§4.1–4.7 describe hh.ru. §4.3/§4.5/§4.6 are common to all sources; hosts, paths and page format are
per-source.
