# Job Hunter — project specification

**The specification lives in [`spec/`](./spec/), split one file per section.** Start at
[`spec/README.md`](./spec/README.md) — the index: every `§` with its file and a one-line summary.

Read **only** the file for the `§` you need; never the whole directory. A `§N.M` citation in code
(`§4.3`, `§7.2`, `§4.11.12`) maps to `spec/N.M-*.md`. Section numbering is frozen — over 1200
comments across `backend/` and `frontend/` cite it.

This file is an entry point only. It holds no requirements and nothing is appended here.
Development history is no longer tracked (see spec §14).
